## إعادة التشغيل
شغّل الأوامر من جذر الحزمة بعد فكها. المختبر Linux x86_64، 9 أنوية مرئية وقرابة 9.7 GiB ذاكرة، Node 24.22.1، Python 3.12.14، Git 2.52.0. Docker غير متاح في PATH. فشل Chromium محلياً عند socket() EPERM. لا نتائج Mac أو CI بعيد.

```sh
node motion.mjs
python3 render.py
python3 test_checkpoint.py
PYTHONPATH=research-deps python3 extract_sources.py
OPENBLAS_NUM_THREADS=2 PYTHONPATH=deps python3 benchmark.py
```

يتطلب الرندر FFmpeg 7.1.5 مع librsvg 2.60 وlibx264 وInkscape 1.4، وخطي Noto Sans Arabic وDejaVu Sans. ثبّت حزم الصوت واستخراج المصادر في أدلة منفصلة باستخدام ملفات المتطلبات المقفلة. قبل الصوت جهّز `models/en.onnx` و`models/en.onnx.json` بمطابقة REPO_LOCK.json. أضف `mkdir -p evidence` إذا شغلت اختبار الاستخراج منفرداً. الحزمة تشمل الكود والعينات والقياسات وسجل Git قابلاً للاستعادة.

## ترتيب الجولة التالية

1. جرّب Habibi-TTS Specialized/MSA على Apple Silicon بعد تحقق سلسلة ترخيص الصوت المرجعي والـvocoder وقياس مساحة/ذاكرة التشغيل. وزن MSA الرسمي 1,348,683,569 بايت قبل التبعيات. ثبّت commit ودون سبب أي تغيير. 10 جمل عربية موجودة في voice-prompts.json. يلزم صوت مرجعي ذاتي أو بإذن.
2. اختبر KittenTTS مقابل Piper على الجمل الإنكليزية نفسها. ثبّت بناءً CPU معزولاً ومحدود الحجم بعد تدقيق اعتماديات Kitten. راجع مخارج 10+10 مع ثلاثة مستمعين. سجّل طبيعية الصوت والوقفات والنطق ومستوى الصوت. شرط المتوسط 4/5، مع صفر لفظ معطوب مؤثر.
3. حافظ على librsvg كمرجع سريع للإنفوغرافيك 2D. اختبر Motion Canvas أو Blender على جهاز يسمح بمتطلبات التشغيل. نفّذ ثلاثة قوالب تحريرية وقارن حركة تخدم معلومة وتوقيت كل مشهد بحل واقعي. صِل الصوت المجاز أولاً، ثم نفّذ 3 مواضيع × لغتين وثلاث صيغ. الفيديو الطويل يحتاج قصة كاملة 5–8 دقائق.
4. اجمع بيانات Scout القانونية من YouTube Data API وبيانات مملوكة. اختبر المرشح ViralMint مع صلاحيات محدودة. جرّب Prefect مقابل n8n لمهمة حقيقية وtimeout وrestart. وسّع اختبار النسخ إلى قاعدة وميديا ومصادر ووجهة مشفرة مستقلة. اختبار SQLite الحالي يغطي الحالة فقط.
5. أضف QA مستقل وتوقيع موافقة وحقوق قبل أي رفع تجريبي. راجع أهلية المنصة والعراق والسياسات الرسمية السارية وقت الربط.
