# حزمة المحتوى الموحدة

## الملفات والغرض

- `lab/templates/content-package-template.json`: قالب مصدر موحد واحد للحزمة، بكل الحقول فارغة/مقفلة افتراضياً.
- `lab/fixtures/content-package-demo-TEST_ONLY.json`: مسودة توضيحية أصلية AR/EN لثلاثة تنسيقات. نص اصطناعي بلا أصول أو ادعاءات واقعية، موسوم TEST_ONLY، وكل بوابات النشر والمراجعة مقفلة. تُستخدم لإعادة الفحوص بعد clone؛ ليست محتوى إنتاج ولا تُنشر.

القالب يستند إلى سجل الموضوع والمهمة والمخرج والموافقة الواردة في `ContentFactory_Implementation_Reference_AR.md`. يبقي الحقائق ومصادرها مرة واحدة في `fact_base`، ثم يحيل كل صيغة/لغة إلى المعرفات نفسها. `revision` وبصمات المصدر/الحزمة تحفظ أثر التعديل والمراجعة.

## ما داخل الحزمة

1. `topic`: معرف وعنوان ثنائي اللغة، الجمهور، احتياج المشاهد، ووعد تحريري واحد.
2. `fact_base.claims`: كل عنصر يستخدم `claim_id`, `text_ar_white`, `text_en`, `claim_type`, `source_ids`, `review_status`, `reviewer_alias`, `reviewed_at_utc`, و`notes`. سجل ادعاء ذري واربطه بمعرف مصدر. لا تنسخ فقرة المصدر؛ أعد الصياغة واربط الادعاء بالدليل.
3. `sources`: كل عنصر يستخدم `source_id`, `title`, `publisher`, `url`, `published_at`, `accessed_at_utc`, `locator`, `snapshot_path`, `sha256`, `reuse_terms_url`, و`license_name`. خزّن بصمة نسخة محلية عند الاحتفاظ بها، وشروط/ترخيص إعادة الاستخدام إذا ستنقل مادة. ذكر الرابط وحده لا يعني السماح بنسخ صورة/نص.
4. `copy.ar_white` و`copy.en`: لكل لغة hook ونص فيديو قصير ونص الشاشة وcaption وCTA؛ شرائح Carousel منفصلة؛ وحلقة YouTube الطويلة بعناوين/افتتاح/أقسام/نقاط/خاتمة/وصف وفصول. الترجمة تكييف تحريري أمين، مو ترجمة آلية حرفية.
5. `assets`: سجل لكل صورة/فيديو/موسيقى/خط/قالب/عنصر خارجي: `asset_id`, `kind`, `path`, `creator`, `source_url`, `license_name`, `license_url`, `permission_evidence`, `attribution`, `sha256`, `allowed_uses`, `review_status`. لا تضف أصلاً ما لم يكن مصدره وترخيصه/إذنه مناسبين ومثبتين. الرسم المولّد بأشكال أصلية داخل المشروع يوثق كأصل محلي ولا يخلط مع أصل خارجي.
6. `platform_adaptations`: override منفصل لـYouTube وTikTok وInstagram وFacebook، مثل title/caption/hashtags/ملاحظات القص الآمن، من دون اسم حساب أو صفحة أو وجهة افتراضية. املأها بعد معرفة مواصفات الحساب/المنصة الفعلية؛ لا تحشر إعداد منصة في النص المرجعي المشترك.
7. `review_gates`: سجل منفصل للمراجعات، مع الحالة والمراجع المستعار ووقت UTC ومعرف دليل. البوابة لا تمرّ بكتابة كلمة الموافقة وحدها؛ يجب حفظ دليل القرار والإصدار الذي راجعه الشخص.
8. `release_control`: المعاينة المحلية مسموحة؛ `external_publication_enabled` و`external_publication_approved` افتراضهما `false`، ولا توجد وجهة افتراضية. لا تغيّرها عبر هذه الحزمة.

## البوابات الإلزامية

- **الحقائق:** كل جملة واقعية قابلة للتحقق لها `claim_id` ومصدر أولي/موثوق وموضع يدعمها. يراجعها إنسان ويثبت القرار على revision وبصمة الحزمة. غياب مصدر، تعارض المصادر، أو معلومة صحية/مالية/قانونية غير مؤهلة = `blocked`.
- **الحقوق:** لكل أصل دليل مصدر وشروط استخدام تسمح باستعماله التجاري والمنصاتي المقصود، النسبة المطلوبة، وبصمة الملف. `unknown`, `pending`, أو ترخيص غير مناسب = `blocked`; لا تضع أصولاً احتياطية غير مرخصة.
- **اللغة والمحتوى:** مراجعان/قائمة تحقق لـArabic white (مفهوم، بعيد عن اللهجة المحلية)، English (سليم وطبيعي)، والتكافؤ بين النسختين من غير إضافة ادعاء في ترجمة واحدة. مراجعة بشرية منفصلة من فحص الشكل.
- **الجودة:** مراجعة hook والإيقاع والوضوح والتسلسل والتباين ومساحة المنصة والترجمة النصية. افحص الفيديو المُصدّر عبر FFprobe؛ نجاح إنشاء MP4 وحده لا يثبت الجودة.
- **الصوت:** كل صوت يحمل مصدر وترخيص وموافقة استماع؛ حالة الصوت العربي الحالي تبقى `blocked_unverified_arabic_voice`. لا توليد/اختيار صوت للإنتاج بسبب نجاح الرندر.
- **التقني:** فحص الأبعاد والإطار/المدة والترميز والترجمات والملفات. المخرج يسجل المسار النسبي، البصمة، الحجم، الأداة/الإصدار والوقت.
- **الإصدار:** يلزم نجاح كل البوابات المرتبطة بالحزمة والإصدار، ومراجع مسمى بصفة مستعارة وسجل موافقة. تعديل النص أو المصدر بعد الموافقة يزيد `revision` ويبطل اعتماد الإصدار السابق. النشر الخارجي يبقى معطلاً حتى تصريح مستقل مستقبلي.

حالات مقترحة للبوابات: `blocked`, `pending_human_review`, `changes_requested`, `approved`. لا تستخدم `approved` بلا مراجع ووقت UTC وأدلة. حالة `local_preview_allowed` لا تساوي موافقة إنتاج أو نشر.

## استخدام القالب

انسخ القالب إلى سجل عمل محلي مستقل، املأ الحزمة والمصادر أولاً، ثم النصوص AR/EN والتكييفات. استخدم alias للموضوع والمراجع إذا لم تكن الهوية لازمة. لا تضع credentials أو روابط خاصة أو بيانات حساب. لا تملأ `approved_revision` ولا تفعّل النشر. احتفظ بأصول الإدخال خارج Git ما لم تكن رخصتها تسمح بإضافتها ويُراجع ذلك صراحةً.

## حدود النموذج الحالي

هذا عقد بيانات وقالب مراجعة، وليس workflow متصلاً أو renderer ديناميكياً. `lab/motion.mjs` الحالي يضم نصوصاً ثابتة ولا يقرأ JSON، و`lab/render_mac.py` يرندر تلك الصور الثابتة؛ لم يتغير أي منهما. عينة الـdemo تثبت بنية AR/EN وتفرعات short/Carousel/long فقط. خطوة الدمج التالية تكون adapter صغيراً يقرأ نسخة مصادقاً عليها من الحزمة إلى renderer بعد اجتياز المراجعات، مع إبقاء النشر معطلاً.
